<h1 align="center">OrbitDisk</h1>
<p align="center">내 Mac의 저장 공간을 한눈에 보는 SwiftUI 디스크 탐색기</p>
<p align="center">macOS 13+ · SwiftUI + AppKit · 현재 버전 2.1.3</p>

![OrbitDisk 앱 창](assets/screenshot.png)

큰 파일과 폴더가 어디에 모여 있는지 원형 지도로 살펴보세요. 앱 창에서는 디스크와 원하는 폴더를 탐색하고, 메뉴 막대에서는 홈 폴더 용량을 빠르게 확인할 수 있습니다.

OrbitDisk는 파일을 읽어 용량을 계산합니다. 파일을 수정하거나 삭제하는 기능은 없습니다.

## 주요 기능

- **원형 용량 지도** — 최대 7단계의 폴더 구조를 표시합니다. 조각의 각도는 용량 비율을, 중심에서의 거리는 폴더 깊이를 나타냅니다.
- **공간에 맞는 폴더 이름** — 여유 있는 조각 안에 이름을 접선 방향으로 배치합니다. 좁은 조각은 비워 두고, 긴 이름은 읽을 공간이 있을 때만 줄임표로 표시합니다.
- **메뉴 막대 홈 요약** — 작은 원형 게이지와 두 줄 용량 표시, 클릭해서 여는 미니 지도, 현재 폴더의 큰 항목 4개를 제공합니다.
- **연결된 탐색** — 지도와 목록의 색상 및 강조 표시가 연결됩니다. 경로 탐색, 뒤로/앞으로 이동, 현재 폴더 검색, 경로 복사, Finder에서 보기를 지원합니다.
- **백그라운드 스캔** — 진행 상태를 확인하거나 취소할 수 있습니다. 메뉴 막대 결과를 재스캔 없이 큰 창으로 이어서 볼 수 있습니다.

## 빠른 시작

### 소스에서 빌드

Apple Command Line Tools의 Swift 컴파일러가 필요합니다. 전체 Xcode 설치는 필요하지 않습니다. 현재 배포용 앱은 Apple Silicon에서 빌드·확인했으며, `build.sh`는 실행한 Mac의 아키텍처를 대상으로 빌드합니다.

```sh
git clone https://github.com/rollrat/OrbitDisk.git
cd OrbitDisk
./build.sh
open build/OrbitDisk.app
```

빌드 결과는 `build/OrbitDisk.app`에 생성됩니다. 로컬 서명을 사용하며 Apple 공증은 받지 않았습니다.

### 처음 실행하면

1. 메뉴 막대에서 홈 폴더 스캔이 자동으로 시작됩니다.
2. 앱 창에서 디스크 또는 폴더를 선택하면 해당 위치를 따로 스캔할 수 있습니다.
3. 지도 조각이나 목록의 폴더를 눌러 들어가고, 지도 중심을 눌러 상위 폴더로 돌아옵니다.

## 메뉴 막대

메뉴 막대 위쪽에는 용량 숫자, 아래쪽에는 `GB · HOME`처럼 단위와 범위를 표시합니다. 원형 게이지는 디스크 전체 용량 대비 홈 폴더에서 읽힌 용량의 비율입니다.

| 동작 | 표시 또는 결과 |
|---|---|
| 앱 실행 | 홈 폴더를 자동 스캔합니다. 최초 결과가 나오기 전에는 `SCANNING`을 표시합니다. |
| 메뉴 막대 클릭 | 홈 폴더의 미니 지도와 용량이 큰 항목 4개를 표시합니다. |
| 지도 조각 또는 폴더 클릭 | 해당 폴더 안으로 이동합니다. |
| 지도 중심 또는 위쪽 화살표 클릭 | 상위 폴더로 이동합니다. `홈` 버튼은 홈 폴더로 돌아갑니다. |
| 새로고침 클릭 | 홈 폴더를 다시 스캔합니다. 하단에서 업데이트 시각과 접근 제한 항목 수를 확인할 수 있습니다. |
| `큰 창에서 보기` 클릭 | 현재 스캔 결과와 탐색 위치를 앱 창으로 넘깁니다. |
| 앱 창 닫기 | 메뉴 막대와 진행 중인 홈 폴더 스캔은 유지됩니다. |
| `… → OrbitDisk 종료` | 앱을 완전히 종료합니다. 앱이 활성화된 상태에서는 ⌘Q도 사용할 수 있습니다. |

메뉴를 닫아도 스캔은 계속됩니다. 결과는 실행 중 메모리에 유지되며, 파일 변경 사항을 반영하려면 새로고침하세요. 메뉴를 다시 열면 홈 폴더부터 보여줍니다. 하위 폴더를 탐색해도 메뉴 막대의 숫자는 홈 폴더 전체 합계를 유지합니다.

## 앱 창

| 동작 | 방법 |
|---|---|
| 폴더 열기 | 지도 조각 또는 목록의 폴더 클릭 |
| 상위 폴더 | 원형 지도 중심 클릭, 또는 ⌘↑ |
| 뒤로 / 앞으로 | 상단 화살표, 또는 ⌘[ / ⌘] |
| 폴더 선택 | 상단 폴더 선택, 또는 ⌘O |
| 현재 폴더 다시 스캔 | 상단 새로고침, 또는 ⌘R |
| 파일 위치 확인 | 파일 선택 후 Finder에서 보기, 또는 목록 우클릭 |
| 경로 복사 | 우측 하단 복사 버튼, 또는 목록 우클릭 |
| 새 폴더 스캔 | Finder의 폴더를 창으로 끌어 놓기 |

작은 항목은 하나의 흐린 조각으로 합쳐 표시하며, 클릭하면 해당 항목 목록을 볼 수 있습니다. 파일에서 끝난 가지는 바깥쪽으로 이어지지 않으므로 폴더 구조에 따라 지도의 모양이 달라집니다. 디스크 선택 화면으로 돌아가도 마지막 스캔 결과를 다시 열 수 있습니다.

## 용량 숫자 이해하기

| 위치 | 의미 |
|---|---|
| 앱 창의 원형 지도 | 현재 탐색 중인 폴더에서 읽힌 파일의 할당 크기 합계 |
| 메뉴 막대의 숫자 | 홈 폴더 전체에서 읽힌 파일의 할당 크기 합계 |
| 메뉴 막대의 원형 게이지 | 디스크 전체 용량 대비 위 홈 폴더 합계의 비율 |
| 디스크 선택 화면 | 시스템에서 조회한 볼륨 용량 및 가용 공간에 따른 사용량 |

파일 합계는 **1GB = 1,000,000,000바이트** 기준의 추정치입니다. APFS 스냅샷, 공유 블록, 하드 링크를 별도로 보정하지 않으므로 macOS나 다른 모니터링 앱의 전체 디스크 사용량과 다를 수 있습니다. 홈 폴더 밖의 앱·시스템 파일도 홈 폴더 합계에는 포함되지 않습니다.

읽지 못한 항목은 합계에서 제외되고 접근 제한 개수로 표시됩니다. OrbitDisk에 부여된 접근 권한에 따라 결과가 달라질 수 있으며, 앱이 권한을 자동으로 변경하지는 않습니다.

## 검증

```sh
./test.sh
```

다음 항목을 검사합니다.

- 각도와 용량 보존, 작은 항목 묶음, 최대 7단계 제한
- 일반 지도와 미니 지도의 조각 클릭 판정
- 폴더 이름의 경계 준수 및 회전 방향: 200개 배치 사례
- 탐색 이력, 검색, 부모 폴더 연결
- 심볼릭 링크 순환 방지 및 스캔 취소
- 메뉴와 앱 창의 탐색 상태 분리, 결과 공유 후 이전 스캔의 덮어쓰기 방지
